Digital Outputs in Sequence

Three words, one big idea. Let's break the name down:

👆 tap
ON · 1OFF · 0
DIGITAL
Only two states: ON or OFF. Like a light switch. No “half on”.
👆 tap
UNO
OUTPUT
The Arduino sends a command out to a part, like an LED.
👆 tap
1→2→3
IN SEQUENCE
Commands run one after another, in order. Change the order and the result changes!

Wire it on the breadboard

🧪
Our Tinkercad class
Code: EHCPPMFGE
Open ↗
For each LED:
  1. Wire from the pin → a column.
  2. 220 Ω resistor from that column → a new column.
  3. LED long leg (+) in the resistor's column, short leg (−) in the next one.
  4. Black wire from the short-leg column → (−) rail.
⚫ Only once: a black wire from the (−) rail to Arduino GND.
🔧 Tinkercad resistors start at 1 kΩ: change to 220 Ω. The bent leg = long leg (+).

Troubleshooting guide

💡 One LED never lights up›
Is the LED backwards? Long leg → pin side. Is a wire loose? Does the pin in your wiring match the number in the const line?
❌ Error: 'CAR_RED' was not declared›
The name is spelled differently somewhere. CAR_RED, Car_Red and CARRED are three different names to the Arduino. Copy the exact spelling from the const line.
🔆 A light turns on and never turns off›
You're missing a digitalWrite(..., LOW); for that light. Follow the code with your finger and check each light gets turned OFF somewhere.
😱 Both greens are on at the same time›
Check the order: CAR_GREEN must go LOW before PED_GREEN goes HIGH, with the everyone-red safety gap between them.
✏️ Error: expected ';' before…›
A line is missing its semicolon ;. Look at the line above the one the error points to.
😴 Nothing happens at all›
Tinkercad: did you press Start Simulation? Real board: is the Board set to Arduino Uno and the right Port chosen? Is the GND rail connected to Arduino GND?
